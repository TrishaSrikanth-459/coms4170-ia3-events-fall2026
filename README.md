# Events

A React/Vite events interface for COMS W4170 Individual Assignment 3. It includes an Events list, event details with RSVP, a My Events page, status announcements, loading and recovery states, a responsive Going count, and title search.

## Run locally

```sh
npm ci
npm run dev
```

Open the local URL shown by Vite. To check the production build, run `npm run build`.

The supplied data and media are fictional course materials. `src/data/loadEvents.js` has two simulation flags for the loading-state exercises; both are set to `false` for normal use.
